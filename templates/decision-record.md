## B. 일반화 템플릿

```markdown
# DECISIONS.md — 의사결정 기록

> 규칙: ID는 재사용하지 않는다. 바뀐 결정은 지우지 않고 "대체됨 → 새 ID"로 표시한다.
> "미확인" 결정은 어떤 문서에서도 확정처럼 쓰지 않는다.
> 문서 우선순위: 이 문서 → 현재 설계 문서 → 과거 자료. 측정 수치는 원본 파일 기준.

## 상태 용어
| 상태 | 뜻 |
|---|---|
| 확정 | 사용자 승인. 설계·구현 기준 |
| 목표·권장 | 방향만 정함. 측정·승인 후 확정 |
| 미확인 | 결정 전. 임의 확정 금지 |
| 대체됨 → D-0XX | 새 결정으로 바뀜 |

## 결정 목록
| ID | 날짜 | 주제 | 결정 | 상태 | 근거·대안 | 승인 | 관련 문서 |
|---|---|---|---|---|---|---|---|
| D-001 | {YYYY-MM-DD} | {주제} | {한 문장 결정} | 확정 | {실측·비교 요약, 기각한 대안} | {사용자 응답 위치} | {링크} |
| D-002 | … | … | … | 대체됨 → D-005 | … | … | … |

## 결정 상세 (필요한 것만)
### D-005 {제목}  (D-002 대체)
- 바뀐 이유: {외부 확인 결과, 실측, 감사 지적 등}
- 영향 받는 문서: {목록}
- 코드 게이트: {설정 이름, 기본값}  ← 외부 전송·유료 호출이면 필수
- 하위 항목: ① … ② …
```

### 작성 점검
- [ ] 결정 전에 실측·대안 비교가 있었나
- [ ] 대체된 결정이 새 ID를 가리키나
- [ ] 되돌리기 어려운 결정에 기본값 off 스위치가 있나
