## B. 일반화 템플릿

### AI가 보내는 질문 묶음

```markdown
## 결정이 필요한 질문 ({N}개)

분류: A = 사용자 결정 필요 / B = 합리적 기본값 있음(추천대로 진행 가능) / C = 표현·중복 정리

| 묶음 | Q | 분류 | 질문 | 추천 | 추천 이유(근거 파일:줄) |
|---|---|---|---|---|---|
| {영역} | Q1 | A | {질문} | {추천안} | {근거} |
| | Q2 | B | … | … | … |

추천대로면 **"전부 추천"**이라고만 답해 주세요. 바꿀 것이 있으면 번호와 내용만 적어 주세요.
답을 받으면: ① 결정 기록 반영 → ② 관련 문서 반영 → ③ 독립 리뷰 재실행 순서로 진행합니다.
지금 정하지 않아도 되는 질문: {Qx, Qy} — 관련 Step 시작 전에 다시 묻겠습니다.
```

### 사용자가 보내는 응답

```markdown
## 결정 응답 ({날짜})
1. **승인** — {그대로 진행}
2. **조건부 승인** — {조건}
3. **변경** — {바꿀 내용}
4. **보류** — {보류 이유, 언제 다시 볼지}

이번 작업 범위: {예: 설계 문서 반영만 / 구현 금지 / 커밋 승인 여부}
```
