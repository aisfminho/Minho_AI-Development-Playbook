# 05. ChatGPT의 기여와 세 AI 협업 구조

> v0.2에서 추가한 문서입니다. v0.1에서 `[통합 대기]`로 비워 둔 ChatGPT 부분을 ChatGPT 내보내기 기록으로 채웠고, Claude Code·Codex 기록과 시각·문장 단위로 대조했습니다.
> 이 문서는 **기록에서 확인된 것만** 씁니다. ChatGPT의 제안이 모두 채택된 것도 아니고, 모든 프롬프트의 원문을 대조한 것도 아닙니다. 확인 수준은 항목마다 표시했습니다.

## 0. 읽는 법

**근거 표기** `gpt:{대화ID 앞 8자}/{메시지 노드ID 앞 8자}` — 예: `gpt:6aed9c1d/7f4ebb09` = ChatGPT 대화 `6aed9c1d…`의 메시지 `7f4ebb09…`. 8자에서도 겹치면 더 늘린다는 원칙이며, 분석한 대화들에서 8자 충돌은 0건입니다(6자 표기에서는 한 대화에서 두 사용자 메시지가 겹쳐 v0.2 수정 때 8자로 통일). Claude Code·Codex 근거는 기존 방식(`d39ff7ed:1149`, `codex1:25`)을 그대로 씁니다. 시각은 모두 KST이고, ChatGPT 기록의 시각이 Claude Code 기록과 같은 시간대임을 같은 사건의 시각 일치로 확인했습니다(예: `gpt:6aed5ec8/…` 11-12 10:04 ↔ `d39ff7ed:465` 11-12 10:04).

**확인 수준**
| 표시 | 뜻 |
|---|---|
| **[사실]** | 해당 기록에서 직접 확인 |
| **[사실: 시각 일치]** | 시각·주제가 맞지만 문장 단위 대조는 하지 않음 |
| **[사실: 문장 일치]** | 두 기록의 본문이 같음을 확인 |
| **[추정]** | 기록들로부터 합리적으로 짐작되나 직접 증거 없음 |
| **[미확인]** | 근거 부족 → [sources/unverified.md](../../sources/unverified.md) |

**분석 범위** ChatGPT 내보내기 1,222개 대화 중 프로젝트 관련 **후보 17개**에서 일반 개발 학습 3개를 제외한 **14개**의 사용자·어시스턴트 텍스트를 읽었습니다(9개는 순차 확인, 5개는 키워드·일부 구간 확인. 기준은 [session-index.md](../../sources/session-index.md)). 첨부 파일, 이미지, 추론(reasoning) 기록, 관련 없는 개인 대화는 읽지 않았습니다. 개인 식별 정보(이름, 학번, 계정, 로컬 경로)와 개인 대화 원문은 이 저장소에 싣지 않았습니다. 세션 목록은 [session-index.md](../../sources/session-index.md).

## 1. 한눈에: 네 주체와 중계 방식

| 주체 | 실제로 한 일 | 한 일이 아닌 것 |
|---|---|---|
| **사용자** | 목표·제약 제시, 외부 확인(지도교수·데이터 제공처), **모든 AI 사이의 중계**, 승인·반려·조건부 승인, 중단 지시 | — |
| **ChatGPT** | 기획, 기술 대안 검토, **Claude Code·Codex용 지시문 초안**, Claude Code 보고서 검토, 단계 순서 조언 | 프로젝트 파일을 직접 읽거나 수정하지 않음(아래 ③) |

| 방향 | 방식 | 근거 |
|---|---|---|
