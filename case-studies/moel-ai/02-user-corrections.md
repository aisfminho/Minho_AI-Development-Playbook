## 사례 상세

### #1 설계 전 구현 선행 [사실]
- 지시: "교수님 답변을 받기 전까지는 **최종 LLM 실행 방식과 배포 환경만 보류하고, 나머지 프로젝트 개발을 진행**하겠습니다"(`d39ff7ed:748`)
- 결과: 백엔드 단건 엔진(Mock LLM + 합성 데이터), API, 테스트 45건(`:1160`)
- 1차 중단: "아직 구현은 하지 마 설계 계획부터 확정지어야해"(`:1149`)
- 2차 중단: Claude가 OpenAI 반영과 다음 구현을 진행한 뒤(`:1167`) 다시 중단. 사용자 문장은 메모리에 "내랑 대화하면서 설계 및 계획부터 할꺼야"로 기록(memory `design-before-implementation.md`)
- 교훈: 기능 목록이 담긴 지시는 계획의 입력. **실행 전에 범위·승인 확인**.

- 교훈: 기술 선택은 외부 이해관계자 확인을 기다려 **그 항목만 보류**.
