# 04. 아키텍처 설계

## 목적

데이터·API·이벤트·상태 전이라는 **계약**을 서로 모순 없이 정의합니다. 구현 에이전트가 여러 명이어도 같은 계약을 보고 일하게 만듭니다.

## 절차 [권장]

1. **핵심 계약 문서를 정합니다.** 보통 다음 5개입니다.
   - 데이터 모델(ERD·DDL·인덱스), API 계약, 실시간 이벤트 계약(SSE 등), 상태 전이 규칙, 주요 시퀀스
2. **핵심 계약은 메인 에이전트가 직접 씁니다.** 주변 문서(화면 설명, 테스트 계획, 운영 문서)만 서브에이전트에 나눠 맡깁니다.
3. **주제마다 단일 기준 문서를 둡니다.** 다른 문서는 요약·링크만 둡니다. 예: "이 문서가 법령 RAG의 단일 기준이며 다른 문서는 요약·링크만 둔다."
4. **헌장 문서는 짧게, 세부는 분할합니다.** 매 세션 불러오는 문서가 길거나 중복되면 컨텍스트를 낭비하고 에이전트를 헷갈리게 합니다. 줄 수 한도는 프로젝트마다 정합니다.
5. **외부 전송 경로를 표로 점검합니다.** 구성 요소마다 `외부로 나갈 수 있는 것 | 차단 방법`(텔레메트리, 추적, 기본 임베딩 함수, 클라우드 모델 이름, 로그 등).
6. **비용 구조를 설계에 넣습니다.** 선불 한도, 앱 내부 한도, 시연 예비비, 한도 초과 시 동작, 유료 테스트 분리 실행.
7. **계산 순서와 표시 순서를 구분합니다.** 내부 계산 순서(예: 근거 검증 → 추천)와 화면에 보내는 이벤트 순서는 다를 수 있으니 둘 다 명시합니다.
8. **저장값 = 조회값 = 전송값.** 같은 상태를 저장·조회 API·실시간 이벤트에서 따로 계산하지 않게 합니다.
9. **병렬 구현에 대비해 공용 파일 소유자를 정합니다.** 공용 파일은 메인 에이전트가 소유하고, 통합 후 테스트를 다시 돌립니다.
10. **설계와 구현 상태를 문서에 표시합니다.** "설계 확정, 미구현"을 상단에 적고, 구현·검증 전에는 화면·발표에서 완료 기능으로 표기하지 않습니다.

## 완료 기준

- [ ] 핵심 계약 문서 5종이 있고, 서로 이름·필드·상태값이 일치한다
- [ ] 주제별 단일 기준 문서가 정해져 있다
- [ ] 외부 전송 경로 점검표와 비용 보호 장치가 있다
- [ ] 독립 리뷰(서브에이전트 또는 다른 도구)를 거쳐 지적이 반영되었다
- [ ] 각 문서 상단에 구현 상태가 적혀 있다

## 흔한 실패와 복구

| 실패 | 복구 |
|---|---|
| 병렬 작성으로 문서끼리 어긋남 | 메인이 직접 맞춘 뒤 독립 리뷰를 한 번 더 |
| 문서(다수결)와 기존 코드(점수 가중)가 다름 | 최소 변경 원칙으로 한쪽에 맞춤(MOEL은 문서를 코드에 맞춤, AUD-23) |
| 테이블 생성이 그 테이블을 처음 쓰는 단계보다 늦음 | DDL을 첫 단계에서 모두 생성(AUD-01) |

## MOEL AI 근거

- **핵심 계약 직접 작성** [보고서]: 메인 Claude가 ERD·인덱스·SSE·시퀀스 4개를 직접 쓰고 주변 문서 5개는 서브에이전트 병렬 작성(`55b37226:664`~`:708`).
- **단일 기준 문서** [사실]: `LEGAL_SEARCH.md` 상단 "이 문서가 법령 RAG의 단일 기준이며 다른 문서는 요약·링크만 둔다. 구현·검증 전에는 화면·발표에서 완료 기능으로 표기하지 않는다"(`44d22df7:1201`).
- **헌장 중복 문제** [사실]: `CLAUDE.md`에 같은 문장이 3번, 문서 역할 표 6행이 3번 반복된 것을 발견 — "중복은 컨텍스트만 낭비하고 에이전트를 헷갈리게 합니다"(`4d23f4bc:118`).
- **외부 전송 점검표** [사실]: Hugging Face 업데이트 확인, ChromaDB 사용 통계, 기본 임베딩 함수, LangSmith 추적, Ollama `:cloud` 모델, 서버 바인딩, 로그, 개발 도구 자체까지 점검(`d39ff7ed:541`).
- **비용 설계** [사실]: LLM API는 소액 선불·자동 충전 꺼짐, 배포 플랫폼은 무료·체험 플랜(만료 조건 있음)으로 시작(`55b37226` 서브에이전트 `ae2ab98d:1`). 추천안: 앱 내부 한도 `OPENAI_BUDGET_USD`를 선불액보다 낮게 두어 여유분 확보, 개발·리허설·시연 용도별 배분, **시연·발표 예비비 고정**, 한도 도달 시 `BUDGET_EXCEEDED`(`55b37226:631`, `:639` Q4). 사용자 최종 응답 형식은 [미확인]. 구체 금액·요금제는 개인 계정 정보라 공개본에서 생략.
- **계산 순서 ≠ 발행 순서** [사실]: 내부는 근거 검증을 먼저, SSE는 화면 계약대로 `recommendation_completed` → `evidence_verified`(AUD-16, `b1t5v1u06.txt:25`).
- **저장값 = 조회값 = 전송값** [사실]: 일괄 작업 종료 상태를 한 함수로 판정해 DB·조회·마지막 이벤트에 같은 값 사용(AUD-02 보완, `b1t5v1u06.txt:269`).
- **공용 파일 소유** [사실]: "공용 파일 소유자 = 메인 에이전트, 고정 엔진 진입점·fixture, 통합 후 TP 재실행"(AUD-28, `09fb2455:630`).
- **LangGraph** [사실]: 헌장 문서에 "LangGraph·모델 파인튜닝·분산 작업 큐는 기본 필수가 아니다. 복잡도가 입증될 때만 … 도입"(`fc1439ba:18`), 사용자 답변 "Q31: LangGraph는 필수 구성에서 제외"(`fc1439ba:57`). Codex 감사 요청서에는 감사 대상으로 남아 있었습니다(`codex1:25`).

| 항목 | 값 |
