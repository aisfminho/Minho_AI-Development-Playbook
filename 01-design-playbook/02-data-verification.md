# 02. 데이터 검증

## 목적

설계·화면·평가에 쓰는 모든 수치를 **실제 파일에서 다시 재고**, 데이터를 어디까지 써도 되는지(외부 전송, 공개 표시) 확인합니다.

## 절차 [권장]

1. **집계만 출력하는 실측.** 원문(개인정보 가능성이 있는 행)은 출력하지 않고 행 수·열 구조·결측·분포만 셉니다.
2. **과거 문서 수치와 대조.** 과제 보고서·기획서의 수치와 실측값을 표로 나란히 놓습니다.
3. **차이는 보고 → 승인 → 결정 기록.** AI가 임의로 고치지 않고, 사용자가 정정을 승인한 뒤 결정 기록에 남깁니다.
4. **수치마다 정의를 붙입니다.** `값 | 정의(무엇의 비율인가) | 분모 | 출처 파일 | 측정 시점`. 정의 없는 수치는 화면·발표에 쓰지 않습니다.
5. **전처리 단계를 숫자로 남깁니다.** `원본 N → 빈 값 제거 −a → 중복 제거 −b → 최종 M`.
6. **데이터 이용 조건을 확인합니다.** 외부 API 전송, 해외 서버 저장, 공개 화면 표시가 허용되는지 제공처 조건으로 확인하고 결정으로 기록합니다. 코드에는 **기본값이 꺼진 스위치**로 연결합니다.
7. **원본이 없으면 있는 데이터로 먼저 진행**하고, 평가 결과를 본 뒤 재수집 여부를 판단합니다. 재수집은 사용자 승인 사항입니다.
8. **정답 데이터의 자격을 따집니다.** 과거 기록이 현재 기준의 정답이 될 수 있는지 확인합니다(예: 과거 담당 부서 ≠ 현행 부서).

## 완료 기준

- [ ] 핵심 데이터셋마다 실측표(행·열·결측·기간)가 있다
- [ ] 과거 수치와 다른 값은 정정 기록과 사용자 승인이 있다
- [ ] 화면·발표에 쓸 수치는 정의·분모·출처가 있다
- [ ] 데이터 이용 조건(외부 전송·공개 표시)이 결정으로 기록되어 있다
- [ ] 출력·로그에 원문이 나가지 않는 규칙이 헌장 문서에 있다

## 흔한 실패와 복구

| 실패 | 복구 |
|---|---|
| 문서마다 수치가 다름 | 실제 파일 기준으로 한 값을 확정하고, 다른 문서는 그 결정을 참조하도록 고침 |
| 비율의 의미를 잘못 설명함(예: 결측률을 업무 누락률처럼) | 정의·분모·출처를 다시 쓰고 문구를 바꿈 |
| 정답 표본이 편향됨 | 편향을 실측으로 보여 주고, 목적에 맞게 보정 범위를 정함(정밀 보정 vs 한계 기록) |

## MOEL AI 근거 [사실]

- **수치 충돌 정정:** 10주차 보고서의 13,558행과 노트북·CSV의 13,597행이 달랐고, 실제 파일 기준인 **13,597행으로 확정**했습니다(`d39ff7ed:341`). 사용자 승인: "13,597행으로의 수치 정정을 승인합니다"(`d39ff7ed:346`). → D-012·D-013 [보고서: ID 대응]
  - 참고: 인수인계 자료의 "13,597행 → 11,380행"은 정정이 아니라 **전처리 결과**입니다: 13,597행 → 빈 값 제거 −2,175 → 중복 제거 −42 → 11,380행(`d39ff7ed:306`). [sources/evidence-map.md](../sources/evidence-map.md) 정정 목록 참고.
- **실측 기준값:** 민원 1,309건(학습 1,080 / 검증 229), 공식 조직·부서 686건, 담당업무·연락처 11,380건(부서명 296종), 담당 부서 기재 267건(20.4%)·결측 1,042건(79.6%)(`d39ff7ed:148`, `:309`).
- **결측 표기 주의:** 부서 결측이 빈칸이 아니라 문자열 `-`였습니다(`d39ff7ed:309`).
- **재수집 보류:** "지금은 … 재수집 요청을 보내지 말고 기존 데이터를 활용 … 원본이 없다면 기존 11,380건으로 … 평가한 후 추가 수집 여부를 결정"(`d39ff7ed:346`).
- **수치의 의미:** 랜딩 화면의 79.6%가 업무 누락률처럼 읽히자, 사용자가 "정확한 의미, 계산 기준, 표본 수, 출처. 검증되지 않은 수치는 사용하지 않습니다"라고 요구(`79503ed4:1174`). → "데이터셋에 부서가 기록되지 않은 비율"로 문구 수정 [보고서: `79503ed4:1199`].
- **정답 자격:** 사용자는 "과거 담당 부서가 기록된 267건은 현행 부서 추천의 정답 데이터로 직접 간주하지 마세요"라고 지시(`44d22df7:649`).
- **편향 실측(Q12):** 학습용 부서 기재 261건 중 현재 담당업무 자료와 부서명이 같은 것은 46건(고유 부서 19개), 261건 중 235건이 '안전' 분야(`bab8244b:928`). 사용자는 정밀 보정을 빼고 한계를 기록하기로 결정(`fc1439ba:193`, D-036).
- **이용 조건:** AI-Hub 원문의 OpenAI 전송·해외 서버 저장·근거 발췌 표시를 허용 확인(D-020), 조건은 명시적 스위치 `AIHUB_EXTERNAL_ALLOWED=true`와 개인정보 마스킹(`09fb2455` 서브에이전트 `a2579273:143`의 SECURITY.md 인용).
