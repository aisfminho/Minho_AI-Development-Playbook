# 미확인 정보와 ChatGPT 통합 대기

## 1. ChatGPT 통합 대기 [통합 대기]

| 항목 | 현재 아는 것 | 필요한 기록 |
|---|---|---|
| ChatGPT의 역할 | 프로젝트에 `GPT.md`("ChatGPT 의견, 계획에 반영 완료")가 있었다는 기록뿐(`d39ff7ed:64` [보고서]) | ChatGPT 내보내기 ZIP |
| 사용자 프롬프트 초안 작성 여부 | 사용자의 긴 지시문(붙여 넣기 형식)이 어디서 작성되었는지 **알 수 없음** | ChatGPT 대화와 Claude 세션 시각 대조 |
| Codex 감사 요청서(`codex_only_requests.md`) 초안 작성 도구 | 사용자가 제공한 Codex 전용 채널 파일. Claude 밖에서 생성됨(사용자 설명 `09fb2455:14`, Claude의 git status에 untracked로 표시 `09fb2455:17`). 초안을 어떤 도구로 썼는지는 알 수 없음 | ChatGPT 대화와 요청서(`codex1:25`) 문장 대조 |
| 설계 판단 기여 | 미확인 | 같은 주제(LLM 선택, UI, 감사 요청서 등)의 ChatGPT 대화 |
| 3자 협업 구조 | Claude Code·Codex만 기록 있음 | — |

### 기록 도착 후 통합 절차 [권장]
1. 내보내기 ZIP을 이 Playbook 밖의 새 빈 폴더에 풀고 읽기 전용으로 둡니다.
2. 대화 목록을 날짜순으로 정리하고, [session-index.md](session-index.md)의 Claude·Codex 세션 시각과 나란히 놓습니다.
3. 사용자가 Claude·Codex에 붙여 넣은 지시문(예: `d39ff7ed:496`, `55b37226:322`, `codex1:25`)과 같은 문장이 ChatGPT 대화에 있는지 대조합니다.
4. 결과를 `case-studies/moel-ai/05-chatgpt.md`로 새로 쓰고, `00-overview.md` 역할 분담표의 ChatGPT 행과 이 문서를 갱신합니다.
5. ChatGPT 기록에서 확인되지 않은 기여는 계속 [미확인]으로 둡니다.
