# 미확인 정보와 ChatGPT 통합 상태

## 1. ChatGPT 통합 상태 (v0.2)

v0.1의 **[통합 대기]** 항목은 ChatGPT 내보내기(약 1,222개 대화) 중 프로젝트 관련 선별 세션을 읽어 통합했습니다. 결과: [case-studies/moel-ai/05-chatgpt.md](../case-studies/moel-ai/05-chatgpt.md).

| v0.1의 대기 항목 | v0.2 상태 |
|---|---|
| ChatGPT의 역할 | **해소.** 기획, 기술 대안, 지시문 초안, 보고서 검토(`GPT.md`와의 관계는 [추정]) |
| 사용자 프롬프트 초안 작성 여부 | **부분 해소.** 상세 설계 1~8·감사 요청서 = ChatGPT 작성(문장 일치). OpenAI 확정 지시문 = 문장 일치. 환경 구성·"개발 진행" 지시문 = 시각 일치. 나머지 붙여넣기 지시문은 [미확인] |
| Codex 감사 요청서 초안 작성 도구 | **해소.** ChatGPT(앞부분 문장 일치). 말미 "추가 프로젝트 상황" 절은 대조 안 함 |
| 설계 판단 기여 | **해소(선별 세션 기준).** 단 Claude Code 설계 문서가 ChatGPT 키트(13·25개 문서)를 **얼마나** 반영했는지는 [미확인] |
| 3자 협업 구조 | **해소.** 자동 연동 없음, 사용자 중계 |

## 3. 공개 전 점검

- [x] 원본 인용에 사용자 계정명·이메일·저장소 URL이 없는지(이번 작성에서 제외함)
- [x] 로컬 절대 경로가 없는지(`<repo>`, `<archive>`로 대체함)
- [x] 로컬 기기 사양 정보가 없는지(제외함)
- [x] 외부 이해관계자(지도교수 등)를 특정할 수 있는 정보가 없는지(제3자 발언 직접 인용은 요약으로 대체함)
- [x] ChatGPT 기록: 이름·학번·계정·로컬 경로·개인 대화·첨부 파일·추론 기록 미포함, 대화 원문 복사 없음, 대화 ID는 앞 8자만 표기(v0.2)
- [x] 실제 세션 백업·ChatGPT 내보내기 파일이 Git에 올라가지 않도록 `.gitignore`에 보호 규칙 적용(`/CHAT_GPT*/`, `conversations-*.json`, `/claude-code/`, `/codex/`, `*.jsonl`, `/quarantine/`, `codex_only_*` 등). 추적 중인 파일이 규칙에 걸리지 않음(`git ls-files -ci --exclude-standard` 결과 0건)을 확인
- [ ] **Git author/committer 메타데이터 검사** — 커밋·push 전마다 `git log --all --format='%h | %an <%ae> | %cn <%ce>'`로 실명·개인 이메일·소속 도메인·로컬 호스트명이 들어 있는지 확인한다. v0.1 커밋 `1f149aa`와 `design-v0.1` 태그의 이메일은 개인 메일(Gmail 등)이 아니라, **Git 신원이 설정되어 있지 않아 Git이 자동 생성한 로컬 로그인명·호스트명 기반의 `.local` 주소**였다. 이름 필드에는 OS 계정의 실명이 들어 있다. 실제 로그인명과 호스트명은 이 문서에 적지 않는다 [사실, v0.2 정정]. 이 값은 이미 원격에 올라가 있다. 원격에 이미 올라간 이력은 **재작성하지 않는다**(공개 여부와 재작성 여부는 사용자가 별도로 판단). 향후 커밋은 공개용 이메일(예: 호스팅 서비스의 noreply 주소)을 **저장소 로컬 설정**(`git config --local user.name / user.email`)에 지정한 뒤 커밋하는 방안이 있으며, **사용자 승인 없이 Git 작성자 정보를 바꾸지 않는다.** 작성자 정보 변경 전의 확인 항목: ① 현재 로컬·전역 설정값, ② 원격 공개 상태, ③ 커밋에 `Co-Authored-By` 등 추가 행이 붙는지
- [x] 커밋 해시: 공개본에서 생략(`<기준 커밋>`·"기준 커밋"으로 표기, 근거는 세션 줄 번호로 유지). 태그 이름은 절차 예시로 유지
- [x] 개인 계정 비용 정보: 구체 금액·요금제를 비용 관리 원칙으로 일반화함
